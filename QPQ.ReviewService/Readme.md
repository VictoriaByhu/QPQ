# QPQ.ReviewService (Проєкт №3 - MongoDB)

Мікросервіс для управління відгуками, обговореннями та репутацією користувачів платформи QPQ.

## 🚀 Порядок розгортання бази даних

1. Встановіть та запустіть MongoDB (локально на порту `27017` або у Docker).
2. Відкрийте MongoDB Compass та підключіться до сервера (`mongodb://localhost:27017`).
3. Створіть нову базу даних з назвою `QPQ_Reviews`.
4. У базі створіть три колекції: `Reviews`, `Discussions`, `Reputation`.
5. Відкрийте кожну колекцію та імпортуйте відповідні тестові дані через кнопку **Add Data -> Import JSON**:
   - `db/p3/reviews-seed.json`
   - `db/p3/discussions-seed.json`
   - `db/p3/reputation-seed.json`
*Примітка: Файли seed-даних є ідемпотентними (містять фіксовані `_id`). Повторний запуск імпорту не створить дублікатів.*

## 📋 Політика дублювання даних та узгодженості

| Поле | Де зберігається | Джерело (власник даних) | Політика узгодженості |
| :--- | :--- | :--- | :--- |
| `fromUserName`, `toUserName` | `QPQ_Reviews` (колекція Reviews) | Identity API (БД Користувачів) | Знімок на момент написання відгуку. Не оновлюється. |
| `authorUserName` | `QPQ_Reviews` (колекція Discussions) | Identity API (БД Користувачів) | Знімок на момент створення обговорення. |
| `userName` | `QPQ_Reviews` (колекція Reputation) | Identity API (БД Користувачів) | Оновлюється асинхронно (eventual consistency) подіями з Identity. |
